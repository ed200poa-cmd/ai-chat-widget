Claude AI Chatbot
for WordPress

A production-ready WordPress plugin that embeds a streaming Claude AI chatbot on any page — one shortcode, instant chat, token-by-token responses.

View on GitHub
👋 Try it now: Click the purple button in the bottom-right corner to open the AI chat widget. It streams live responses from Claude claude-sonnet-4-6 token by token — the same experience embedded in a WordPress site.
⚡

Token-by-Token Streaming

Uses Server-Sent Events (SSE) to stream Claude's response in real time. No waiting — words appear as they're generated.

🔌

WordPress Shortcode

Add [ai_chat_widget] to any page or post. The floating chat button appears instantly, fully configured from the admin panel.

🗄️

Conversation History

Every message is stored in PostgreSQL with pgvector extension installed — RAG-ready for future semantic search over past conversations.

🎨

Fully Customizable

Set the widget title, primary color, and welcome message from the WordPress admin panel. No code changes required.

🔒

Secure by Design

The Anthropic API key lives only on the FastAPI server. It's never exposed to the browser. CORS configured for production use.

🚀

One-Click Deploy

Backend deploys to Railway via Dockerfile. PostgreSQL plugin added in one command. Environment variables auto-injected.

Tech Stack

Built end-to-end with modern, production-grade tools
